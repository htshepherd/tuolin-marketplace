# `$tuolin-avatar-video` 纵向切片开发文档

## 文档状态

- 来源：`docs/prd/tuolin-avatar-video.md`
- 当前状态：AFK 实现完成（S01–S16 已通过自动验收）；S17 真实付费 HITL 待执行
- GitHub Issue：按用户要求不创建；本文作为本地开发、依赖和验收记录
- 拆分方式：Tracer Bullet 纵向切片。每个切片必须贯穿相关 Skill 指令、自然语言入口、运行状态、持久化产物、用户可见结果和外部行为测试，不能只交付某一层内部重构。

## 类型说明

- **AFK**：需求和验收标准已经明确，可以由开发 Agent 独立实现和自动验证。
- **HITL**：需要用户查看真实外部供应商产物或授权真实付费动作后才能最终验收。

## Slice 01 — 数字人口播专属知识接口最小闭环

- **类型**：AFK
- **Blocked by**：无，可立即开始
- **覆盖用户故事**：11–20

### What to build

交付从正式知识索引到 `tuolin-avatar-video` 专属投影、验证器和读取 API 的最小闭环。接口支持至少一个正式产品，拥有独立 manifest 和 revision，声明禁止 raw 访问，并证明不读取视频策划、完整视频或 legacy context。

### Acceptance criteria

- [x] 专属接口拥有独立 agent ID、manifest、revision、source knowledge revision、产品索引和允许卡片投影。
- [x] 接口声明 `raw_access=false`，读取 API 不接受任意 raw 路径。
- [x] 读取 API 能列出正式产品、按ID读取允许卡片，并拒绝草稿或不存在产品。
- [x] 数字人口播消费者只通过专属 API 读取，不解析其他 Agent 投影。
- [x] 构建后验证 manifest、产品数量、卡片数量、预期卡片和持久化 revision。
- [x] 自动测试删除 legacy context 后仍能读取数字人口播投影。

## Slice 02 — 英文30秒伪供应商最小成片 Tracer

- **类型**：AFK
- **Blocked by**：S01
- **覆盖用户故事**：1–10、38、48–55、69、74、81–82、91–97、107、109、114–120

### What to build

交付第一条窄而完整的端到端路径：显式调用新 Agent，使用完整请求跳过访谈，从专属接口选择一个正式产品和一张正式图片，生成并确认30秒英文生产方案，使用伪 Fish 和伪 HeyGen 产物，通过最小 FFmpeg 合成得到可验证的9:16本地视频，完整确认后生成交付包。该切片先证明所有层连通，不追求完整供应商能力或视觉效果。

### Acceptance criteria

- [x] 只有显式 `$tuolin-avatar-video` 调用能创建独立运行目录和状态。
- [x] 完整请求可直接进入生产方案草稿，不创建趋势研究或其他视频 Agent 状态。
- [x] 一次方案确认锁定逐字稿、时间线、素材和伪供应商首次执行。
- [x] 伪 Fish 音频、伪 HeyGen 视频和一张正式图片贯穿到最终9:16视频。
- [x] 最终视频可由媒体探测器读取，时长、尺寸、音轨和非空校验通过。
- [x] 最终确认生成本地交付包，不包含发布动作或平台凭据。
- [x] 端到端测试不联网、不产生真实费用，并验证旧两个视频 Agent 行为未改变。

## Slice 03 — 知识写入自动刷新、多产品投影与 revision 固定

- **类型**：AFK
- **Blocked by**：S01
- **覆盖用户故事**：12–20

### What to build

把专属接口接入知识写入后的统一刷新事务，扩展到多个正式产品，并让数字人口播运行固定创建时的接口 revision。构建失败采用隔离快照，不破坏上一个可读版本，上游知识操作明确报告 incomplete。

### Acceptance criteria

- [x] 数字人口播 builder/verifier 注册到统一 Agent-specific interface registry。
- [x] 产品整理、更新、复核写回和视频档案发布均触发自动刷新与验证。
- [x] 专属产品索引支持多个正式产品且不写死石英纤维隔热带。
- [x] 任一注册接口失败时上游操作不报告完成，并保留上一个有效快照。
- [x] 新运行固定 interface revision 和产品投影指纹。
- [x] 缺失、stale 或验证失败接口阻止创建和恢复运行。
- [x] 测试明确显示全项目 legacy 迁移仍未完成，不误报所有旧消费者已隔离。

## Slice 04 — 无趋势动态访谈与完整生产方案确认

- **类型**：AFK
- **Blocked by**：S02、S03
- **覆盖用户故事**：21–55

### What to build

交付独立动态访谈到完整生产方案的路径。系统提取初始请求中的已知答案，每轮只提出一个承重业务问题、一个推荐和一个理由；决策充分后生成包含策略、完整逐字稿、30–90秒连续时间线、数字人/证据区间、素材、字幕、供应商设置和预计消耗的联合方案，一次确认同时锁内容并授权已披露首次执行。

### Acceptance criteria

- [x] 访谈跳过已知答案，任意时刻最多一个待确认问题。
- [x] 每问只有一个推荐和具体理由，普通确认只作用当前问题。
- [x] 访谈字段不包含平台趋势搜索、固定创意方向或专业剪辑选项。
- [x] 决策充分性覆盖受众、观看理由、记忆点、行动、优先信息、排除项、平台、语言、时长和数字人/证据关系。
- [x] Agent稿和用户稿统一进入完整逐字稿合同。
- [x] 高风险审查只提示明确知识冲突、参数、认证、测试、绝对性能和安全承诺。
- [x] 方案时间线连续且等于30–90秒目标，所有受保护字段和消费范围可见。
- [x] 一次方案确认同时锁定内容并授权所有已披露首次调用；修改受保护字段使确认失效。

## Slice 05 — 正式图片检查、证据画面和数字人退场时间线

- **类型**：AFK
- **Blocked by**：S04
- **覆盖用户故事**：51、57–64、82

### What to build

把像素级素材检查和证据边界接入生产方案。正式产品图、参数、测试、认证和真实应用画面必须来自专属接口并经过主体、清晰度、构图、9:16裁切和近重复检查；方案允许旁白连续时数字人退出，正式证据全屏接管。

### Acceptance criteria

- [x] 每张入选正式图片具有像素检查记录和原始引用。
- [x] 路径失效、未检查、错误产品、权利/隐私或证据风险阻止确认。
- [x] 近重复图片归组，意外重复不计为独立素材容量。
- [x] 素材不足时阻止方案确认，并只接受缩短时长、明确重复或受约束模拟三种用户决策。
- [x] 事实型画面只能引用正式证据，不接受生成图作为参数、测试或真实案例证明。
- [x] 时间线支持数字人区间和全屏证据区间，旁白保持连续。
- [x] Codex方案确认视图显示真实预览，不只显示路径或元数据。

## Slice 06 — 首次执行授权、不可变供应商尝试与幂等提交

- **类型**：AFK
- **Blocked by**：S02、S04
- **覆盖用户故事**：52–56、83–89、118–120

### What to build

交付供应商执行协调器和不可变尝试账本。一次方案确认授权已披露初次调用；重复命令不会重复收费。用户拒绝结果后可明确授权同一运行内重试，每次输入、设置、任务ID、消耗、输出、审查和拒绝原因版本化保存，并精确使依赖确认失效。

### Acceptance criteria

- [x] Provider Attempt schema不保存秘密，包含输入revision/指纹、设置、任务ID、费用、输出和审查结果。
- [x] 同一确认与输入指纹只能提交一次，重复命令返回既有尝试。
- [x] 方案确认覆盖所有已披露首次调用，不产生单独首次付费确认。
- [x] 新增范围、改变设置或任何付费重试需要新的明确授权。
- [x] 重试创建新尝试且保留旧输出和拒绝原因。
- [x] 依赖图只清除受影响的音频、图片、数字人、包装和交付确认。
- [x] mock、dry-run、failed和rejected不能被当作真实已确认输出。

## Slice 07 — 辅助图片批次、并行生成与联合输入验收

- **类型**：AFK
- **Blocked by**：S05、S06
- **覆盖用户故事**：52、56、62–73

### What to build

交付受约束辅助图片的完整路径：方案披露精确数量、用途、真实产品参考和预计消耗；确认后与Fish音频并行生成；完成后在一个Codex视图中展示完整音频和全部图片，通过一次回复建立确认音频与确认图片集。

### Acceptance criteria

- [x] 批次精确记录供应商、数量、逐张用途、产品参考、提示合同和预计消耗。
- [x] 含产品生成图必须绑定已检查真实产品图，不得创建事实、认证、测试或客户证据。
- [x] 默认不添加观众可见AI/示意标签，内部保留生成来源。
- [x] Fish与辅助图片任务并行启动，不人为串行等待。
- [x] 联合验收视图提供完整可播放音频和每张真实像素图片。
- [x] 一次回复同时确认音频和图片集；任一拒绝不会错误推进依赖阶段。
- [x] 重生成需要新批次授权，并保留旧图片和拒绝原因。

## Slice 08 — Fish Audio 真实适配器与完整音频确认

- **类型**：AFK
- **Blocked by**：S06、S07
- **覆盖用户故事**：48、53–55、68–74、83–88

### What to build

实现可替换Fish Audio适配器的生产合同和伪服务集成。适配器只消费已确认逐字稿、固定voice ID和方案设置，生成完整音频、标准化元数据和可审阅文件；联合验收通过后才建立确认音频。

### Acceptance criteria

- [x] 适配器接口支持提交、取得结果、错误分类和媒体元数据，不泄漏供应商响应到业务状态机。
- [x] 输入文本逐字等于确认旁白，供应商不能静默改写。
- [x] voice ID、语言、速度和输入revision固定在尝试记录中。
- [x] 输出必须存在、非空、可探测并具有合理音频时长和规格。
- [x] 用户必须完整试听；短样本、文本确认或任务完成不能建立确认音频。
- [x] 新音频版本不会继承旧确认，HeyGen拒绝未确认音频。
- [x] 自动测试使用伪服务覆盖成功、失败、超时、畸形响应和重试，不调用真实付费API。

## Slice 09 — HeyGen 固定 public Avatar 与完整原片确认

- **类型**：AFK
- **Blocked by**：S08
- **覆盖用户故事**：53–55、74–81、83–88

### What to build

实现HeyGen适配器合同和固定public Avatar生产路径。适配器只接收确认音频、版本化avatar ID和方案设置；完整原片可播放并经用户检查口型、表情、动作、构图、身份和稳定性后，才建立确认数字人原片。

### Acceptance criteria

- [x] 固定public Avatar ID及版本写入运行配置，不能按运行静默切换。
- [x] HeyGen拒绝未确认音频、错误revision或缺失授权元数据。
- [x] 适配器隔离提交、任务状态、结果取得和错误分类。
- [x] 输出必须存在、非空、可播放并通过媒体探测。
- [x] 任务完成不等于通过，必须展示并完整观看原片。
- [x] 新原片版本不会继承旧确认，HyperFrames拒绝未确认原片。
- [x] 自定义Digital Twin保留为可替换avatar ID，不进入首版创建流程。

## Slice 10 — HyperFrames 合成与 FFmpeg 自动保底

- **类型**：AFK
- **Blocked by**：S07、S09
- **覆盖用户故事**：81–82、90–96

### What to build

建立实现无关的组合时间线，并交付HyperFrames首选合成和FFmpeg确定性保底的端到端路径。两种执行器消费同一确认输入和时间线；HyperFrames缺失或失败时自动降级，不重复访谈或确认方案。

### Acceptance criteria

- [x] 组合合同包含音频、数字人、证据/辅助图、字幕、连续时间和平台规格。
- [x] HyperFrames只消费确认原片和确认图片集，失败返回明确可分类错误。
- [x] HyperFrames缺失、失败或输出不完整时自动触发FFmpeg保底。
- [x] FFmpeg保底保持脚本、素材、时间线和事实含义，只简化不支持动效。
- [x] 自动降级不增加确认门禁，最终摘要记录实际合成路径。
- [x] 输出通过分辨率、帧率、像素格式、音轨、时长、非空和可播放性检查。
- [x] 测试用fixture证明两条执行路径产生同一内容顺序和可交付媒体。

## Slice 11 — 同语种硬字幕、默认无 BGM 与用户音乐输入

- **类型**：AFK
- **Blocked by**：S10
- **覆盖用户故事**：97–104

### What to build

把字幕和简化音频包装接入组合合同。英文生成英文硬字幕，中文生成中文字幕，默认不双语；Agent负责时间、断句、样式和安全区。默认无BGM且访谈不问音乐，只有用户显式提供本地曲目时才加入。

### Acceptance criteria

- [x] 字幕文本来自确认旁白，时间与最终音频及连续时间线一致。
- [x] 英文运行只生成英文字幕，中文运行只生成中文字幕。
- [x] 默认烧录字幕；只有方案确认前显式取消才输出无硬字幕版本。
- [x] Agent自动处理断句、样式和平台安全区，不询问专业设计参数。
- [x] 默认无BGM，运行不搜索、下载、许可或选择音乐。
- [x] 用户提供音乐时验证文件存在和可读，并作为显式包装输入，不改变旁白内容。
- [x] FFmpeg和HyperFrames路径遵循同一字幕/BGM合同。

## Slice 12 — 英文 YouTube Shorts 与中文快手/抖音双版本

- **类型**：AFK
- **Blocked by**：S11
- **覆盖用户故事**：35、38–41、97–108

### What to build

扩展交付范围：英文运行产生一个9:16 YouTube Shorts文件；中文运行建立一个内容母版并派生快手与抖音两个版本，复用同一音频、数字人、事实素材和核心时间线，仅调整安全区、结尾和编码。

### Acceptance criteria

- [x] 只接受英文YouTube Shorts或中文快手+抖音组合，不接受其他平台。
- [x] 一个运行只有一种语言；中文操作者可以用中文审阅英文任务。
- [x] 时长接受30–90秒任意整数，所有输出固定9:16。
- [x] 中文两个变体引用同一确认音频、数字人、证据、图片集和核心时间线。
- [x] 中文变体不会重复调用Fish、HeyGen或图片生成。
- [x] 允许差异仅限平台安全区、结尾处理和技术编码，并记录在变体清单。
- [x] 自动测试验证英文一个文件、中文两个文件及各自媒体规格。

## Slice 13 — 包装层快速修订与精确依赖失效

- **类型**：AFK
- **Blocked by**：S06、S10、S11
- **覆盖用户故事**：83–87、110–113

### What to build

交付自然语言包装修订路径。字幕、标题/参数排版、用户提供BGM、转场和已确认素材时机只创建新包装revision并重渲染；逐字稿、音频、数字人、事实或证据变化按依赖图回退准确上游节点。

### Acceptance criteria

- [x] 包装字段变更更新真实组合合同和产物，不只记录请求。
- [x] 包装修订不重复访谈、方案确认、Fish或HeyGen调用。
