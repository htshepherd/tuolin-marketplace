# Separate LinkedIn review-pool discovery from dispatch selection

New `tuolin-linkedin-search` runs collect a configurable human-review pool before any invitation count is known. Discovery uses balanced first-pass shares across operator phrases, verified infinite-scroll exhaustion, broad evidence-based preliminary assessment, and one account-scoped cumulative Excel workbook with contact, evidence, and immutable dispatch-history sheets. The workbook is the boss-facing review projection; deterministic run state and the shared ledger remain authoritative for workflow, capacity, and concurrency. The boss's exact current selection becomes an immutable final dispatch snapshot, with no fixed ten-person run ceiling. Rolling 168-hour capacity is evaluated only after selection: zero capacity blocks Connect but not discovery, and insufficient capacity requires the boss to choose an exact reduced subset instead of automatic first-N truncation. Boss feedback may inform later reasoning, but only an explicitly confirmed, versioned screening rule changes hard behavior.
