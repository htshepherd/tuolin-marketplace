# Use agent-specific knowledge read interfaces

Downstream agents will no longer share one general-purpose knowledge projection. Each agent owns an independently generated and verified read interface—with its own manifest, revision, card indexes, filtering policy, and validation—while all interfaces continue to derive from the same formal knowledge base so facts are not duplicated. Every successful knowledge organization, update, or review write-back automatically rebuilds and verifies all registered required interfaces; users never perform a separate refresh, and a failed verification leaves the knowledge operation incomplete and the affected stale interface unavailable. Adoption is phased: the first slice creates the registry and migrates `$tuolin-video-planner`, while existing consumers may temporarily retain the explicitly labeled legacy shared interface; project-wide isolation cannot be reported complete until those consumers are migrated separately.
