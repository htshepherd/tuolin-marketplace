# Separate digital-avatar video production

Tuolin uses the independent `$tuolin-avatar-video` consumer for presenter-led videos built from formal product knowledge, confirmed narration, authorized voice and avatar providers, product materials, and final packaging. It does not add digital-avatar generation or final-editing stages to `$tuolin-video-planner` or `$tuolin-video-workflow`, because the three workflows have different creative contracts, paid actions, acceptance gates, run artifacts, and terminal deliverables; they share formal source knowledge only through separate verified Agent interfaces and may reuse business-neutral media primitives.

The Agent stops after the user watches and accepts a local delivery pack: one English 9:16 YouTube Shorts file or paired Chinese Kuaishou and Douyin variants. It never logs into or uploads to a publishing platform, and final-video acceptance is not publication authorization; a separate publisher consumer owns external posting and its confirmation gates.

Every digital-avatar run must complete its own adaptive, one-question-at-a-time interview before planning. It confirms one duration from 30 through 90 seconds and reaches decision sufficiency independently; it may reuse the existing video-creation interview method but never another agent's brief, run state, or knowledge projection.

The digital-avatar workflow deliberately excludes public platform-trend research. Its plan uses the dedicated knowledge interface, confirmed user decisions, inspected official materials, and disclosed general creative judgment; the existing `$tuolin-video-workflow` trend stage is not inherited.
